What you need

Small enough to run anywhere.

One container and Postgres

ShipLean runs as a single container with a Postgres database. There is nothing else to stand up.

No cloud account

It does not need an internet connection to work, so it can live on a private network.

Every team in one place

Run every team’s projects on one server instead of one subscription per team.

Not published yet.

Sign-in Planned

Bring your own sign‑in.

Put ShipLean behind the identity proxy you already run, such as Cloudflare Access, Authelia or Authentik, and people arrive signed in with their existing account. This is planned and not built yet.
