Privacy policy

Last updated: 5 November 2026

ShipLean is open-source software that organisations can host themselves. This policy describes the ShipLean website and how the ShipLean software handles information, including when a project connects a YouTube channel. The organisation operating a self-hosted instance controls its configuration and data and may have its own privacy policy.

Information in a ShipLean instance

An instance can store account information such as names and email addresses, project membership, work items, comments, attachments, sprint data and other information that users enter or import. Depending on how the operator configures sign-in, an identity provider may supply account information. Instance operators decide where the database, attachments, backups and logs are stored and how long they are retained.

ShipLean can connect to services such as GitHub, GitLab, Jira, identity providers and agent services when an operator or user configures them. Those services receive the information needed for the selected integration and have their own privacy practices. The operator controls which integrations are enabled.

YouTube integration

A project administrator can choose to connect a YouTube channel using Google's authorization screen. ShipLean requests permission to manage YouTube content using the youtube.force-ssl scope. This permission is broader than uploading: it can allow access to, changes to and deletion of YouTube content. ShipLean uses it to identify the connected channel, upload sprint demo videos, read the uploaded videos' visibility and run a connection check that uploads and attempts to delete a small test video.

When a demo is forwarded, ShipLean sends the video, its title, chapter description and chosen visibility to YouTube. ShipLean stores channel and connection information and a protected authorization token on the instance so it can upload future demos. The instance also retains its own copy of the demo as an attachment. YouTube processes uploaded content under Google's Privacy Policy and the YouTube Terms of Service.

A project administrator can disconnect the channel in Project settings → Demos → YouTube. ShipLean attempts to revoke the Google authorization and clears the stored token. If Google does not confirm revocation, remove ShipLean's access in your Google account connections. Disconnecting does not delete videos already uploaded to YouTube or the copies stored in ShipLean; delete those separately using YouTube Studio and the instance's own data management processes.

Retention and your choices

The operator of your ShipLean instance controls retention, backups and deletion of instance data. Contact that operator to request access to, correction of or deletion of your information. Removing an integration or content from an instance may not remove copies retained by an external service or in backups; ask the operator about its retention practices.

Website and security

The ShipLean website is hosted using Cloudflare. Requests to the site may be processed by Cloudflare and may include technical information such as IP address and request details for delivery and security. The website can save your selected light or dark theme in your browser's local storage.

Changes and contact

We may update this policy as ShipLean changes; the date above identifies the latest revision. For questions about ShipLean or this policy, contact the project through ShipLean's GitHub issue tracker. Do not include secrets or sensitive personal information in a public issue. For data held by a self-hosted instance, contact its operator directly.
